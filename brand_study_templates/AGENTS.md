# Product constraints

These constraints describe Nitrosend's maintained publication. In a separately owned fork, follow the fork owner's customization requests. Fork owners may rebrand and edit their copy directly. Keep each Nitrosend editor URL paired with its catalog ID and revision, and never include source credentials or private account data.

Preserve the approved hero composition, genuine PNG icon and serif wordmark artwork. No typed substitute logo and no em dashes. The page is a branded collection that opens the existing Nitrosend editor. Never add another editor, signup gate, draft model, source editor or export application.

All 306 brand studies and 25 Originals come from the pinned API publication, across 36 brands. Night Run is an Original. Do not replace the collection with the three hero brands. Canonical previews and editor links must agree on template ID and revision. Import publication metadata, do not invent links or copy private account IDs.

Use the product-root immutable media publication process for new campaign media. Keep source credentials and source-account migration maps out of this project. Test mobile and desktop in a real browser and verify the full Open in editor path before review.
